# Hermes Mobile Watch (移动看护与即时审批伴侣)

专为在 WSL2 / 本地运行的 Hermes Web UI (Ekko Studio) 打造的同局域网移动端协同审批看护服务。

## 🌟 核心特性

1. **零侵入架构**：完全独立运行（端口 8649），不修改 Hermes Agent 和 Hermes Web UI 的核心逻辑与数据库。即使伴侣服务关闭，主程序照常运行。
2. **🖥️ PC 桌面后台系统级弹窗看护 (全新增强)**：
   - 🔔 **全局常驻弹窗 (Notification API)**：当 Agent 产生待审批命令时，无论用户是在 Chrome 浏览其他网页，还是将 Chrome 最小化在后台使用其他软件干活（写代码/看文档/游戏），屏幕右下角/角标均会**直接弹出系统级桌面通知**！
   - 🔇 **静音免疫 (requireInteraction)**：弹窗设为持久停留（不会几秒后自动溜走消失），即使电脑处于静音状态，强烈的视觉弹窗也不会漏掉审批。
   - 🎯 **点击直达与窗口唤醒 (Focus & Quick Approve)**：点击系统弹窗，浏览器立即**自动拉起并切换回 hermes-web-ui 所在的标签页**；同时页面居中弹出**「极速审批卡片」**，一键点击「允许一次 / 本次会话 / 永久 / 拒绝」，无需在复杂的聊天记录中翻找审批条！
   - ✨ **双重防漏**：后台审批时标签页 Title 交替闪烁（`【⚠️ 待审批!】Ekko Studio`），右下角胶囊化身呼吸警报灯。
   - 🧪 **一键自检测试**：支持在悬浮挂件中点击「测试后台桌面弹窗」，倒计时 3 秒后模拟后台弹窗并测试窗口唤回。
3. **📱 手机专属触控优化**：专为智能手机（微信浏览器、Safari、Chrome）打造的响应式界面，拥有大号触控按钮（允许执行一次 / 本次会话允许 / 永久允许 / 拒绝）。
4. **强感官即时提醒**：
   - 🔊 **提示音**：内置 Web Audio API 合成音频，零外部资源依赖，审批到来时即时清脆警报。
   - 📳 **连续震动**：调用浏览器 Vibration API 震动提醒。
   - ⚡ **保持常亮**：支持 Screen Wake Lock，手机放在桌面上不会黑屏断连。
5. **PC 端一键扫码协同**：
   - PC 浏览器页面右下角常驻「📱 手机看护」悬浮胶囊，点击即可在「🖥️ 电脑桌面看护」与「📱 手机扫码看护」间自由切换。
   - 终端支持 `./mobile-watch.sh qr` 打印 ASCII 二维码。

## 🚀 常用命令

```bash
# 启动伴侣服务
./mobile-watch.sh start

# 查看运行状态
./mobile-watch.sh status

# 在终端显示扫码二维码与局域网链接
./mobile-watch.sh qr

# 停止伴侣服务
./mobile-watch.sh stop

# 重启伴侣服务
./mobile-watch.sh restart

# 注入 PC 浏览器悬浮挂件（带自动备份）
./mobile-watch.sh install-widget

# 卸载 PC 浏览器悬浮挂件（还原原网页）
./mobile-watch.sh uninstall-widget
```

## 📱 访问说明

确保手机连接到与电脑相同的 Wi-Fi（局域网）：
* **移动端看护地址**：`http://192.168.31.159:8649`
* **PC 原生界面地址**：`http://localhost:8648`
