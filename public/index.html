❓ 常见问题排查与维护指南 (Q&A)
遇到网络无法连接、Hermes 更新后挂件恢复或常用运维管理命令？请参考以下指引
🌐 电脑本机打不开 http://192.168.x.x:8649，但手机可以打开？
局域网与网络
原因分析：本项目服务运行在 Windows 的 WSL2 虚拟环境中。手机访问走物理无线网卡端口转发进 WSL2，所以正常；而电脑本机若直接输入自己的物理局域网 IP，请求在 Windows 宿主机网络栈内部回环时缺少 Hairpin NAT 转发支持，会被系统拦截。
解决方案：
• 💻 电脑本机浏览器：请始终使用 http://localhost:8649 访问。
• 📱 外部手机/平板：连接同一 Wi-Fi 后，使用 http://192.168.31.159:8649 访问（或直接扫码）。
🔄 Hermes Web UI 升级后，电脑网页右下角看护小圆球不见了？
版本更新与挂件
原因分析：升级 Hermes Web UI 时，npm 会覆盖其前端静态客户端文件（index.html），导致注入的挂件标签被覆盖。此时看护助手后台服务、所有配置及手机端均正常运行，未受任何损坏。
一键恢复方法：在电脑终端中执行下方命令，即可重新自动注入并恢复：
cd ~/.hermes-web-ui/mobile-watch && ./mobile-watch.sh install-widget
💡 运行完成后，在电脑端 http://localhost:8648 页面按 Ctrl + F5 强制刷新即可恢复悬浮球。
🛡️ 看护助手代码会被 Hermes 升级替代或清除吗？
数据与安全
结论：绝对不会！代码百分百安全。
1. ~/.hermes-web-ui 是您的持久化用户数据目录（存放数据库与个人配置），Hermes 更新只会替换其 npm 安装包，绝不会清空用户的个人目录。
2. 本项目 mobile-watch 目录已独立初始化为 Git 仓库（main 分支），享有完整的本地版本控制与提交记录保护。
cd ~/.hermes-web-ui/mobile-watch && git status

界面与交互

⚡ 看护助手常用运维管理命令速查（终端执行）
常用命令
1. 查看服务运行状态与手机二维码：
cd ~/.hermes-web-ui/mobile-watch && ./mobile-watch.sh status
2. 重启看护助手服务（配置变更或故障热重启）：
cd ~/.hermes-web-ui/mobile-watch && ./mobile-watch.sh restart
3. 实时查看后台日志流：
tail -f ~/.hermes-web-ui/mobile-watch/server.log
4. 停止看护助手服务：
cd ~/.hermes-web-ui/mobile-watch && ./mobile-watch.sh stop
